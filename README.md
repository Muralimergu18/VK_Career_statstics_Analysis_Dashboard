# 🏏 Virat Kohli Career Statistics Analysis Dashboard

## 📊 Project Overview

This project presents an interactive cricket analytics dashboard developed using Microsoft Power BI to explore Virat Kohli's career performance. It transforms cricket statistics into meaningful visual insights, helping users understand batting performance, scoring trends, and achievements across different formats and years.

## 🎯 Key Features

* **Performance Metrics:** Displays total runs, batting average, strike rate, and innings.
* **Batting Achievements:** Visualizes the distribution of fifties and centuries.
* **Format Analysis:** Filters statistics by cricket formats.
* **Year-wise Analysis:** Tracks performance trends across selected years.
* **Interactive Visualizations:** Uses charts, KPI cards, and filters for easy exploration.
* **Career Insights:** Helps identify performance patterns and compare achievements over time.

## 🛠️ Tech Stack

* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Data Visualization
* Data Analysis
* Business Intelligence

## 💡 Project Objective

To demonstrate practical skills in data cleaning, KPI development, interactive dashboard design, and sports data analytics by converting cricket statistics into an engaging and informative visual report.
